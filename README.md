# 生機古文｜國文家教講義與學習資源平台

一個以**簡約文青書卷風**設計的線上國文講義與教材下載平台，提供國、高中學生免費線上閱讀「題解、作者、原文、賞析」，並可自由下載 `.docx` 與 `.pdf` 講義原檔。

## 專案特色
- **跨年段學習脈絡**：完整收錄「生機古文」國中與高中選文總目錄，清晰標示跨年段核心篇目，支援學段篩選、上架狀態篩選與關鍵字即時搜尋。
- **線上導讀＋雙格式下載**：已上架篇目皆提供無干擾的純文字深度閱讀網頁（支援字級放大切換），並附有 Word（`.docx`）與 PDF（`.pdf`）雙格式下載入口。
- **Agentic Workflow 規範驅動**：透過專案根目錄的 `AGENTS.md` 明確定義目錄架構、命名邏輯、視覺色票與四步驟上架驗收流程，讓 AI 協作擴充新講義時能維持高度一致性。

## 目錄結構
- `AGENTS.md`：專案開發與 AI 協作規範書
- `index.html`：平台首頁（全篇目目錄與篩選器）
- `lessons/`：單篇線上講義網頁
- `files/`：講義原檔下載區（`.docx` / `.pdf`）
- `assets/`：共用樣式表 `style.css` 與互動腳本 `app.js`
- `log.md`：平台內容更新日誌
